# spotdiff

8枚ページ

## 操作方法

異変を見つけたら「引き返す」を押す。正常なページだと確信したら「進む」を押す。

1. ページ1で異変は発生しない
2. ページ2以降は50%の確率で異変が発生する
3. 正しい操作をすると次のページへ進む。ミスするとやり直し
4. ページ8に到達でクリア

## がんばり

- ライブラリ不使用
- たくさんの異変
- レスポンシブ PC/スマホ

## dev

クローンして開発用スクリプトを実行

```bash
# 開発サーバー起動 (Port: 8000)
./dev.sh
```

[http://localhost:8000/](http://localhost:8000/)

ただの静的サイトなのでこれ以外でも良い
